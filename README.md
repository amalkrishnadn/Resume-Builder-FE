# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

------------------------------------------------------------------------
1. create a project using vite -npm create vite@latest
2. clear all unwanted styles form index.css and app.css
3. clear unwanted code from app.jsx
4. integrated material ui (mui) - npm install @mui/material @emotion/react @emotion/styled
5. installed react icons - npm install react-icons --save
